# AQA Java Tests

Учебный проект по автоматизации тестирования на Java.

##  Стек технологий:
* **Java 22**
* **JUnit 5** (юнит-тесты)
* **Selenium WebDriver** (UI-тесты)
* **Page Object Model** (паттерн проектирования)
* **REST Assured** (API-тесты)

##  Что внутри:
* `CalculatorTest.java` — простые Unit-тесты.
* `LoginTest.java` + `LoginPage.java` — UI-тесты для сайта saucedemo.com, написанные по паттерну Page Object.
* `ApiTest.java` — проверка API GitHub.

##  Как запустить:
1. Склонируйте репозиторий.
2. Откройте проект в IntelliJ IDEA.
3. Запустите классы с тестами (Run).
